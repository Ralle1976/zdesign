03 — Integration

Ein API-Call. Vier Zeilen. Lauffähig.

Das Kinetix-SDK ist TypeScript-first, 24 KB gzipped und tree-shakbar. Autocomplete schlägt Task-Typen und Custom Fields direkt in der IDE vor — basierend auf dem Live-Schema Ihres Workspaces.

  • Offline-Modus bei mobilen Geräten — bis zu 5.000 Tasks, dann Auto-Sync.
  • Granulare RBAC auf Client-Seite — sensible Projekte bleiben unsichtbar.
  • SSO & SCIM für Okta, Azure AD und Google Workspace — integriert in einen Aufruf.
  • Versionierung wird automatisch archiviert — auch bei Löschungen.
Zur vollständigen Doku
project-setup.ts 
// 1. Install via npm
import { Kinetix } from '@kinetix/sdk';

// 2. Initialize client
const kinetix = new Kinetix({
  apiKey: process.env.KINETIX_KEY,
  workspace: 'acme-corp'
});

// 3. Create a new task
await kinetix.tasks.create({
  title: "Implement OAuth 2.0 flow",
  sprint: 42,
  priority: "high",
  tags: ["backend", "auth"]
});
